# 매뉴얼 테스트 기록 양식

AI가 만든 매뉴얼만 보고 업무를 처리할 수 있는지 확인하는 테스트입니다.
응시자는 해당 업무를 처음 하는 사람(팀원 등)이 맡고, 매뉴얼 외의 도움은 받지 않습니다.
막혀서 담당자에게 물어봤다면 "되물었는지"에 표시하고 그 내용을 적습니다.

- 테스트 날짜:
- 매뉴얼 파일: `manuals/<id>.md`
- 매뉴얼 버전 (판단 기준 답변 반영 여부): 반영 전 / 반영 후
- 응시자:
- 출제자(담당자):

| 문제 번호 | 상황 | 정답 | 응시자 답 | 정답 여부 | 담당자에게 되물었는지 | 되물은 내용 |
|---|---|---|---|---|---|---|
| 1 | 예: 오늘 기준 IT 업체 점검 현황을 내려받으세요 | 위탁업체점검_YYYYMMDD.csv (IT만) | | O / X | 예 / 아니오 | |
| 2 | 예: 조회 결과가 0건이면 어떻게 하나요? | (판단 기준 답변 내용) | | O / X | 예 / 아니오 | |
