    업무 녹화 매크로 AI

    한 번 보여 주면,
    다음부터는 알아서.

    업무를 한 번 시연하면 매뉴얼과 다시 실행되는 매크로가 함께 만들어집니다.

    🌐 웹 사이트📊 Excel 파일📘 PDF 매뉴얼🔗 업무 연결✨ AI 도우미
    녹화 중 ●
    1로그인 버튼 클릭
    2'점검결과' 필터 → 부적합
    3담당자 열 채우기
    🧠 AI 해석
    📘 매뉴얼
    ⚡ 매크로
    01

    이렇게 동작해요

    왼쪽 메뉴 순서 그대로 4단계면 끝

    1. 🎬녹화사이트나 Excel에서 평소처럼 업무를 한 번녹화 탭 →
    2. 🧠해석단계로 정리 + 다음에 바뀔 값(날짜·파일 등) 찾기해석 탭 →
    3. 📘매뉴얼질문 몇 개에 답하면 완성 · 고치기 · PDF매뉴얼 탭 →
    4. ⚡실행값만 바꿔 자동 실행 · 문제가 생기면 멈춤실행 탭 →
    02

    무엇을 녹화할 수 있나요

    녹화 탭에서 버튼 하나로 고릅니다

    🌐사이트
    • 가상 대학 포털(출석·댓글), 가상 증권사(조회·다운로드·등록)
    • 자주 쓰는 주소는 ☆ 즐겨찾기
    • 누른 곳은 스크린샷에 빨간 상자로 표시
    📊Excel
    • 필터 · 정렬 · 행 삭제 · 값/수식 입력 · 열·시트 추가
    • 다른 달 파일에도 그대로 적용 (행 수가 달라도 OK)
    • 원본은 절대 안 바뀜 — 결과는 _결과.xlsx
    03

    AI가 도와줘요

    녹화한 뒤에도 AI가 정리·답변·수정·검토를 맡습니다

    🧭업무·화면 개요이 업무가 무엇이고, 화면마다 무슨 일을 하는지 한눈에 정리해석 탭에서 보기 →
    💬매뉴얼에 물어보기"이 단계는 왜 하나요?" — 근거와 함께 답하고, 답을 매뉴얼에 추가매뉴얼 탭에서 쓰기 →
    ✍️말로 고치기"담당자를 박예시로" 처럼 말하면 매크로·매뉴얼을 고치고 시험 실행까지매뉴얼 탭에서 쓰기 →
    🛡️수정 검토매뉴얼을 고치면 빠진 단계·실패 위험을 저장 전에 알려 줌매뉴얼 탭에서 쓰기 →
    04

    시연 영상

    보고 싶은 영상을 눌러 보세요

    05

    꼭 알아 두세요

    🏢실제 업무에 사용회사 시스템 화면·내부 엑셀 파일을 녹화해 매뉴얼과 매크로로 만들 수 있습니다
    🔐AI는 사내 API로실제 업무에서는 Gemini(외부) 대신 회사 내부 AI로 바꿔 쓰세요. .env 몇 줄만 바꾸면 됩니다
    🧪시험은 가상 데이터로기능 시험·시연은 함께 든 가상 시스템과 샘플 파일로 합니다
    🛟멈추면 사람에게0건·오류·양식이 다르면 그 단계에서 멈춥니다. 엑셀 원본은 바뀌지 않습니다
    📄 자세한 안내 전체 보기 (실행안내.md)
    녹화 대상
    ⭐ 즐겨찾기누르면 시작 주소에 들어갑니다

    ⚠ 실제 업무 화면입니다. 지금 AI가 외부 서비스(Gemini)에 연결되어 있어, AI를 켠 채 해석하면 스크린샷이 회사 밖으로 전송됩니다. 내부 정보는 사내 AI로 바꾼 뒤 쓰거나 왼쪽 아래 AI 스위치를 끄고 진행하세요.

    📊 원본 파일은 바뀌지 않고 복사본이 Excel로 열립니다. 시연을 마치면 Excel 창(통합 문서)을 닫으세요.
    기록되는 작업: 필터 · 정렬 · 행 삭제 · 값/수식 입력(채우기 포함) · 열 추가 · 시트 추가. 피벗 · 서식 · 차트는 기록되지 않습니다.

    ⚠ 직접 올린 파일입니다. 지금 AI가 외부 서비스(Gemini)에 연결되어 있어, AI를 켠 채 해석하면 Excel 화면이 회사 밖으로 전송됩니다. 내부 정보는 사내 AI로 바꾼 뒤 쓰거나 AI 스위치를 끄고 진행하세요.

    ⚠ 이 PC에 Microsoft Excel이 없어 엑셀 녹화를 할 수 없습니다.
