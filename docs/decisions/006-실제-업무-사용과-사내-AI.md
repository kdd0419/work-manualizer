# 006. 최종 목표는 실제 업무 사용 — 시험은 가상 데이터, 실제 업무 AI는 사내 API

- 날짜: 2026-11-26
- 상태: 결정 (001의 '녹화 대상은 가상 시스템뿐' 원칙을 바꿈)

## 배경
처음 원칙(001)은 "실제 회사 시스템·데이터는 절대 쓰지 않는다"였다. 이는 **개발·시험 단계**에서
내부 정보가 녹화 파일이나 외부 AI로 새는 것을 막기 위한 것이었다.
팀의 최종 목표는 이 프로그램을 **실제 업무에서 쓰는 것**이므로, 사용 단계에서는 회사 시스템 화면과
내부 엑셀 파일(내부 정보)을 녹화할 수 있어야 한다.

## 결정
| 구분 | 데이터 | AI 연결 |
|---|---|---|
| 개발·시험·시연·평가 | 가상 시스템(mock_system), 샘플 엑셀(samples)만 | Gemini 무료 API (외부) |
| 실제 업무 사용 | 회사 시스템·내부 파일 가능 | **회사 내부 AI(API)로 교체** |

- AI 연결은 `.env`만 바꿔 교체한다 (`LLM_PROVIDER=openai`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`).
  사내 AI 게이트웨이·사내 설치 모델 대부분이 쓰는 **OpenAI 호환 형식**을 지원한다 (추가 패키지 없음).
- 이미지를 못 받는 사내 모델은 `LLM_SEND_IMAGES=false`로 글만 보낸다. 사내 인증서 문제는 `LLM_VERIFY_SSL=false`.
- 외부 AI(Gemini)가 연결된 상태에서 실제 업무 대상(가상 시스템이 아닌 주소, 직접 올린 엑셀)을 녹화하려 하면
  관리 화면이 경고한다. 사내 AI로 바꾸거나 AI 스위치를 끄면 경고가 사라진다.
- AI 없이도(규칙 기반) 모든 기능이 동작하므로, 사내 AI가 준비되기 전에는 AI를 끄고 실제 업무에 쓸 수 있다.

## 그대로 두는 것
- 사용자 데이터(녹화, 올린 파일, 실행 결과, 즐겨찾기, 업무 연결, .env)는 각자 PC에만 두고 저장소·공유 묶음에 넣지 않는다.
- 엑셀 원본은 바꾸지 않는다 (복사본 작업, 결과는 새 파일).
- 비밀번호는 녹화에 저장하지 않는다 (`***`).

## 확인
- 가짜 사내 AI 서버(OpenAI 호환)로 글·이미지·JSON 응답, JSON 모드 미지원 서버, 이미지 끄기를 시험해 통과.
- 기존 Gemini 연결도 그대로 동작.
