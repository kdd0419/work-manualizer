# 003. 사용자 화면을 Streamlit 대신 HTML 관리 화면으로 바꾼다

- 날짜: 2026-11-18
- 상태: 결정됨

## 상황
과제로 제출해야 해서, 채점자가 터미널 명령 없이 화면을 열고 모든 기능을 쓸 수 있어야 한다.
처음에는 프롬프트 문서대로 Streamlit 화면(app/main.py)을 만들었다.

## 고민한 선택지
1. **Streamlit 유지 + 실행 파일(start.bat)만 추가**: 가장 빠르지만 화면이 Streamlit 기본 모양이고,
   직접 만든 HTML 화면이 아니다.
2. **Flask + 직접 만든 HTML/CSS/JS 화면 + 더블클릭 실행**: 작업량은 늘지만 화면 구성을 원하는 대로 할 수 있고,
   가상 업무 시스템과 같은 Flask를 써서 기술 스택이 단순해진다.
3. **Python 없이 HTML 파일 하나로 동작하는 데모**: 녹화(Playwright)와 매크로 실행은 브라우저 밖에서
   브라우저를 조작해야 하므로 HTML만으로는 불가능하다. 흉내 낸 데모가 되어 실제 기능이 빠진다.

## 결정
선택지 2. `app/server.py`(Flask API) + `app/static/`(HTML/CSS/JS). `setup.bat`(설치), `start.bat`(실행)을 둔다.
Streamlit은 의존성에서 뺀다.

## 이유
- 실제 기능(녹화·해석·매크로 실행·평가)을 모두 화면에서 쓸 수 있다.
- 녹화·매크로 실행·평가는 별도 프로세스로 돌리고 화면은 로그를 주기적으로 받아 보여 주므로,
  오래 걸리는 작업 중에도 화면이 멈추지 않는다.
- 관리 화면(8000)이 가상 업무 시스템(5000)을 함께 켜 주므로, 채점자는 start.bat 하나만 실행하면 된다.

## 부가 결정
- 가상 데이터는 설치할 때 "실행한 날" 기준으로 만든다. 평가는 고정 기준일(2026-11-18) 데이터로 하고,
  끝나면 다시 오늘 기준으로 되돌린다. (채점 날짜가 달라도 '오늘' 기본값으로 조회 결과가 나오도록)
