# 002. AI 해석에 Google Gemini API 무료 등급을 사용한다

- 날짜: 2026-11-18
- 상태: 결정됨

## 상황
5~7단계(단계 해석, 변수 인식, 판단 기준 질문)는 스크린샷과 이벤트 기록을 LLM에 보내야 한다.
이미지 입력이 되는 LLM이 필요하고, 프로젝트 예산은 0원이다.

## 고민한 선택지
1. **유료 API (Anthropic, OpenAI 등)**: 품질은 좋지만 크레딧 충전이 필요하다.
2. **Google Gemini API 무료 등급**: 카드 없이 키를 받을 수 있고 이미지 입력을 지원한다.
   요청 횟수 제한이 있고, 무료 등급에서는 보낸 데이터가 모델 개선에 쓰일 수 있다.
3. **로컬 모델 (Ollama)**: 완전 무료이고 제한이 없지만, 개발 PC(RAM 16GB, 내장 그래픽)에서는
   느리고 품질이 낮다.

## 결정
선택지 2. Gemini API 무료 등급을 쓴다. 모델 이름은 `.env`의 `LLM_MODEL`로 정한다.

## 이유
- 비용이 들지 않으면서 스크린샷 해석에 충분한 품질을 기대할 수 있다.
- 녹화 대상이 전부 가짜 데이터라서(001 결정), 무료 등급의 데이터 사용 조건이 문제가 되지 않는다.
- 무료 모델 이름과 한도는 자주 바뀌므로 코드에 고정하지 않고, `python -m analyzer.llm_client --list`로 확인한다.
- LLM 호출을 `analyzer/llm_client.py` 한 곳에 모아 두었으므로, 한도가 부족하면 이 파일만 바꿔
  유료 API나 Ollama로 옮길 수 있다.

## 대응 규칙
- 한 요청에 여러 단계를 묶어 보내 요청 횟수를 줄인다.
- 스크린샷은 가로 1024px JPEG로 줄여 보낸다.
- 429(한도 초과) 오류는 5초→10초→20초 간격으로 재시도한다.
