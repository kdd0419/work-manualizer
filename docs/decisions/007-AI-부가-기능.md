# 007. AI 부가 기능 — 개요·수정 검토·질의응답·말로 고치기

- 날짜: 2026-11-26
- 상태: 결정

## 배경
녹화 → 매뉴얼·매크로 생성 이후에도 AI가 도와야 할 일이 있다:
업무와 화면을 한눈에 정리하기, 사람이 고친 매뉴얼의 실수 잡기, 매뉴얼에 없는 질문에 답하기,
영상을 다시 찍지 않고 말로 매크로·매뉴얼을 고치기.

## 결정
| 기능 | 모듈 | AI 없을 때 |
|---|---|---|
| 업무·화면 개요 | analyzer/overview.py | 화면 제목·주소·시트 기준 규칙 기반 |
| 수정 검토 | analyzer/review.py | 코드 검사만 (단계 누락, 번호, 데이터 변경 표시, 이미지, 급격한 축소) |
| 질의응답 | analyzer/assistant.py | 사용 불가 |
| 말로 고치기 | analyzer/edit.py | 사용 불가 |

- 말로 고치기 안전장치
  - AI는 허용된 필드(FIELDS)만 바꿀 수 있다. 엑셀 열 이름은 실제 시트 머리글로, 수식은 형식으로 검사한다.
  - 웹 요소 변경은 해당 단계 직전까지 실제로 실행해 화면 요소 목록을 읽고, 그 목록 안에서만 고른다.
    뒤 단계가 깨지면 같은 방식으로 최대 6번 이어서 맞춘다.
  - 변경안은 데이터 변경 없이 숨김 시험 실행을 거친다. 사용자가 [적용]을 눌러야 반영되고, 이전 매크로·매뉴얼은 보관된다.
  - 다른 사이트처럼 녹화가 필요한 변경은 "녹화 필요"로 답하고, 부분 재녹화 + 업무 연결을 안내한다.
- 질의응답 답에는 근거 수준(근거 있음/일부 추정/추정/일반 지식)을 붙인다. "왜"는 추정일 수 있음을 숨기지 않는다.

## 확인 (2026-11-26, Gemini)
- 개요: 웹·엑셀 예시 AI/규칙 기반 모두 생성.
- 수정 검토: 7단계 삭제 시 코드 3건 + AI 1건 경고.
- 질의응답: 근거 표시와 함께 답변.
- 말로 고치기: 엑셀 값·필터 변경(시험 성공 → 적용 확인), 설명만 변경, 다른 사이트 요청(녹화 필요 + 대안),
  웹 메뉴 변경(뒤 단계 자동 맞춤 후 모든 단계 성공).
