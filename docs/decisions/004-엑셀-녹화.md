# 004. 엑셀 파일 작업 녹화 — 실제 Excel 연동 + 상태 비교 방식

- 날짜: 2026-11-23
- 상태: 결정

## 배경
웹 화면뿐 아니라 엑셀 파일로 하는 업무(조건으로 거르기, 값 입력, 합계 만들기)도 녹화해 매뉴얼과 매크로로 만들고 싶다.
웹 녹화기는 페이지 안에 스크립트를 넣어 클릭을 기록하는데, Excel 프로그램에는 이 방법을 쓸 수 없다.

## 검토한 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 웹 엑셀 편집기를 직접 만들기 | Excel 없는 PC에서도 동작 | 진짜 Excel 화면이 아님, 지원 기능 제한 |
| **실제 Excel 연동 (선택)** | 진짜 Excel에서 시연, 시연 효과가 큼 | Windows + Excel 필요, 메뉴 클릭은 직접 기록 불가 |
| 작업 전·후 파일 비교 | 가장 단순·안정 | '녹화' 느낌이 약함, 순서 정보 없음 |

팀 결정: 시연 효과를 위해 **실제 Excel 연동**.

## 방식
1. **녹화** (`recorder/excel_record.py`)
   - 원본 파일을 복사해 작업본을 Excel로 연다 (원본은 절대 수정하지 않음).
   - Excel 메뉴 클릭은 밖에서 알 수 없으므로, 0.5초마다 통합 문서 상태(셀 수식·값, 필터 조건, 시트 목록)를 읽어 직전 상태와 비교한다.
   - 바뀐 점을 분류: 필터 / 정렬(행 묶음 같고 순서만 다름) / 행 삭제(남은 행이 원래 순서를 지킨 부분 목록) / 셀 변경 / 시트 추가·삭제·이름 변경.
   - 바뀔 때마다 Excel 창을 캡처 (다른 창에 가려져 있어도 되는 PrintWindow).
2. **해석** (`analyzer/excel_interpret.py`): '몇 번째 행'이 아니라 다른 파일에도 맞는 **규칙**으로 바꾼다.
   - 지운 행에만 있는 값 → "점검결과가 '적합'인 행 삭제"
   - 필터로 보이는 행에만 같은 값 입력 → "보이는 행의 담당자 열 채우기"
   - 표 바로 아래 행 → "아래 행 추가" (합계 행)
   - 규칙을 못 찾으면 열쇠 열(점검번호처럼 값이 모두 다른 열)로 행을 지정
3. **실행** (`runner/excel_macro.py`): 다른 파일(다른 달)을 복사해 Excel로 같은 작업을 하고 `_결과.xlsx`로 저장.
   - 수식 범위 자동 확장: 녹화 파일 61행·실행 파일 73행이면 `SUMIF(C2:C61, …)` → `SUMIF(C2:C73, …)`
   - v4 실패 감지: 파일 없음, 머리글이 녹화 때와 다름, 필터·삭제 뒤 0행, 수식 오류(#DIV/0! 등), 찾는 행 없음
   - 멈추면 그때까지의 작업을 `_중단.xlsx`로 저장해 사람이 이어서 처리

## 한계 (매뉴얼·발표에서 밝힐 것)
- 기록되지 않는 것: 피벗 테이블, 서식(색·글꼴), 차트, 열 삽입으로 표 전체가 밀리는 작업, 정렬의 2차 기준
- 0.5초 안에 여러 작업을 하면 한 번의 변경으로 합쳐 보일 수 있다. 연속된 행 삭제·한 칸씩 입력은 해석 때 다시 묶는다.
- Windows + Microsoft Excel이 있는 PC에서만 녹화·실행된다. (관리 화면은 Excel이 없으면 안내 문구를 보여 준다)

## 개발 중 발견해 고친 문제
- COM에서 이름 옵션(`Sort(Header=…)`, `Add(After=…)`)이 조용히 무시됨 → 위치 인자와 Excel 정렬 객체 사용
- 상태를 세 번 나눠 읽는 사이에 행이 지워져 수식·값이 서로 다른 순간의 것이 됨 → 마지막에 다시 읽어 같을 때만 채택
- 행을 여러 번에 나눠 지우면 조건 추정 실패 → 연속된 삭제를 합쳐서 추정
- 양식이 다른 파일에서도 v4가 '성공' → 파일을 연 직후 머리글 위치 비교
