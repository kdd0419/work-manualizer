## 처음 시도에서 잘 안 된 점과 고친 방법
1. **Python이 없다고 잘못 판단** — Anaconda Python이 PATH에 없었을 뿐. Anaconda Python으로 `.venv` 생성.
2. **녹화 이벤트 순번 중복** — 스크린샷을 찍는 동안 다음 이벤트 처리가 끼어듦 → 순번을 먼저 정하고 목록에 넣은 뒤 스크린샷.
3. **submit 이벤트에 폼 전체 글자가 들어감** — 폼 요소는 텍스트를 비우도록 수정.
4. **DB 연결이 닫히지 않음** — `with get_conn()`이 커밋만 하고 닫지 않아 Windows에서 DB 재생성 시 파일이 잠길 수 있음 → contextmanager로 닫기.
5. **규칙 기반 설명에 녹화값이 박힘** — 값이 바뀌면 설명과 실제가 달라 보임 → 설명에서 값을 빼고 값은 따로 표시.
6. **Streamlit 1.67에서 `use_container_width` 폐기** → `width="stretch"`로 변경.

## 추가 작업: HTML 관리 화면으로 교체 (과제 제출용)

- 프롬프트 요약: "과제로 제출해야 해서 HTML 화면을 켜면 그 화면에서 기능을 쓸 수 있게" → HTML 웹 화면 + 더블클릭 실행 + 실행 안내 문서
- 만든 파일: `app/server.py`(API·백그라운드 작업), `app/static/index.html·style.css·app.js`, `setup.bat`, `start.bat`,
  `eval/run_all.py`, `실행안내.md`, `docs/decisions/003-HTML-관리화면.md`. Streamlit 화면(`app/main.py`) 삭제
- 확인 결과: Playwright로 관리 화면을 직접 눌러 해석→매크로→질문→매뉴얼(스크린샷 15장 로드)→매크로 실행(변경 미허용 시 저장 직전 멈춤,
  허용 시 15/15 성공)→평가 결과까지 확인, 콘솔 오류 없음. 화면의 평가 실행 경로로 v1 10/30, v3 28/30, v4 30/30 재현
- 잘 안 된 점과 고친 방법
  1. CSS `display`가 HTML `hidden` 속성을 덮어써 숨겨야 할 영역이 보임 → `[hidden]{display:none!important}`
  2. 메뉴 링크 "점검 결과 **등록**"이 데이터 변경 단계로 잘못 분류 → 링크(a)는 제외하고 버튼·POST 제출만 판단
  3. 메뉴 카드 링크의 대상 이름이 설명 문장까지 포함해 너무 김 → 녹화기가 링크 안 제목(strong)을 `short_text`로 따로 기록
  4. 채점 날짜가 데이터 범위를 벗어나면 '오늘' 조회가 0건 → 설치 시 오늘 기준 시드, 평가 후 오늘 기준으로 복원
