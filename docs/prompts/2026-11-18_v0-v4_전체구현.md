## 처음 시도에서 잘 안 된 점과 고친 방법
1. **Python이 없다고 잘못 판단** — Anaconda Python이 PATH에 없었을 뿐. Anaconda Python으로 `.venv` 생성.
2. **녹화 이벤트 순번 중복** — 스크린샷을 찍는 동안 다음 이벤트 처리가 끼어듦 → 순번을 먼저 정하고 목록에 넣은 뒤 스크린샷.
3. **submit 이벤트에 폼 전체 글자가 들어감** — 폼 요소는 텍스트를 비우도록 수정.
4. **DB 연결이 닫히지 않음** — `with get_conn()`이 커밋만 하고 닫지 않아 Windows에서 DB 재생성 시 파일이 잠길 수 있음 → contextmanager로 닫기.
5. **규칙 기반 설명에 녹화값이 박힘** — 값이 바뀌면 설명과 실제가 달라 보임 → 설명에서 값을 빼고 값은 따로 표시.
6. **Streamlit 1.67에서 `use_container_width` 폐기** → `width="stretch"`로 변경.
